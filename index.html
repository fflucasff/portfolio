Quem sou na prática

Mais do que “fazer site”, meu foco é estruturar presença digital que gera resultado. Venho da Engenharia de Computação no INATEL e atuo como desenvolvedor web, apoiando negócios que precisam de páginas rápidas, estáveis e pensadas para performance — tanto técnica quanto comercial.

Stack principal

  • Front-end com React + TypeScript
  • Back-end com Python (FastAPI)
  • Banco de dados com PostgreSQL
  • Estilização moderna com Tailwind CSS
  • Versionamento com Git e GitHub

Visão orientada a negócio

  • Criação de landing pages focadas em conversão
  • Integração com tracking (RedTrack, pixels, parâmetros UTM)
  • Estruturação de páginas para campanhas (YouTube, Taboola, Outbrain)
  • Experiência com checkouts como CartPanda e funis de venda

Como trabalho

Começo entendendo o objetivo do projeto (captar leads, vender, validar uma oferta) e, a partir disso, desenho a estrutura técnica: páginas, componentes, integrações e métricas que realmente importam. Comunicação clara, entregas frequentes e foco em manter tudo simples de operar no dia a dia.

O que posso fazer pelo seu negócio

Minha entrega é ponta a ponta: da página até o tracking. Você não precisa “correr atrás de um dev” toda vez que mudar campanha ou oferta.
